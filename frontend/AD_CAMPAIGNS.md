## TRACKING & ANALYTICS SETUP

### Google Ads Conversion Tracking

1. **Go to:** Google Ads > Tools > Conversions
2. **Click:** + New Conversion Action
3. **Select:** Website
4. **Category:** Purchase (for paid subscriptions) or Submit Lead Info (for newsletter)
5. **Value:** Set to subscription price (e.g., $99 for Industrial Database)
6. **Count:** One (don't count duplicates)
7. **Conversion Window:** 30 days
8. **Attribution Model:** Last Click

**Install Global Site Tag** in `/index.html` (if not already installed):
```html
<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=AW-XXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'AW-XXXXXXXXX');
</script>
```

**Fire Conversion on Stripe Success:**
Add this to each success page (e.g., `/industrial-database?success=1`):
```javascript
if (window.location.search.includes('success=1')) {
  gtag('event', 'conversion', {
    'send_to': 'AW-XXXXXXXXX/CONVERSION_LABEL',
    'value': 99.00,
    'currency': 'USD'
  });
}
```
