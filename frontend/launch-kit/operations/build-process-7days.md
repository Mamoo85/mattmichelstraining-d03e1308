# 7-DAY WEBSITE BUILD PROCESS

This is your step-by-step guide to deliver a professional contractor website in 7 days.

---

## PRE-LAUNCH CHECKLIST (Before Day 1)

□ Contract signed
□ Deposit received
□ Client questionnaire completed
□ Photos received (minimum 5)
□ Logo received (or create one)
□ Domain name identified
□ Hosting account ready

**If any of these are missing, project doesn't start until complete.**

---

## DAY 1: SETUP & STRUCTURE

### Morning (2-3 hours)
□ Create project folder
□ Set up development environment
□ Register/configure domain name
□ Set up hosting (Netlify, Vercel, or similar)
□ Choose design template from your demos
□ Customize color scheme to match client brand

### Afternoon (2-3 hours)
□ Build basic HTML structure
□ Create navigation
□ Add header with logo
□ Set up all page files (home, about, services, gallery, contact)
□ Add footer with contact info
□ Test responsive design basics

**End of Day 1 Deliverable:** Basic site structure with navigation and branding

---

## DAY 2: HOME PAGE & ABOUT PAGE

### Morning (3 hours)
□ Design hero section with strong headline
□ Add CTA button (call now, get quote, etc.)
□ Create services overview section
□ Add social proof (if available)
□ Optimize and add hero image

### Afternoon (2-3 hours)
□ Write "About Us" page copy
  - Company history
  - Why choose us
  - Credentials/licenses
  - Service area
□ Add team photo (if available)
□ Add trust badges (licensed, insured, etc.)

**End of Day 2 Deliverable:** Completed home page and about page

---

## DAY 3: SERVICES & GALLERY

### Morning (3 hours)
□ Create detailed services page
□ List all services client offers
□ Add descriptions for each service
□ Include pricing (if client wants it public)
□ Add service-specific CTAs

### Afternoon (2-3 hours)
□ Build photo gallery
□ Optimize all client photos (compress, crop, enhance)
□ Add captions/descriptions
□ Organize into categories if needed
□ Add before/after slider if applicable

**End of Day 3 Deliverable:** Services and gallery pages complete

---

## DAY 4: CONTACT PAGE & FUNCTIONALITY

### Morning (2-3 hours)
□ Create contact form
  - Name, Email, Phone, Message fields
  - Service type dropdown
  - Preferred contact method
□ Set up form submission (FormSpree, Netlify Forms, or similar)
□ Test form delivery to client email
□ Add click-to-call phone buttons throughout site

### Afternoon (2-3 hours)
□ Add Google Maps embed
□ Create service area map or list
□ Add business hours
□ Add social media links
□ Set up favicon
□ Test all internal links

**End of Day 4 Deliverable:** All pages complete, form working

---

## DAY 5: SEO & POLISH

### Morning (3 hours)
□ Add meta titles and descriptions (all pages)
□ Optimize image alt tags
□ Create sitemap.xml
□ Add robots.txt
□ Implement schema markup (LocalBusiness)
□ Add Google Analytics (if client wants)
□ Set up Google Search Console

### Afternoon (2-3 hours)
□ Review all content for typos
□ Check mobile responsiveness on multiple devices
□ Test load speed (aim for under 3 seconds)
□ Optimize any slow-loading elements
□ Cross-browser testing (Chrome, Safari, Firefox, Edge)

**End of Day 5 Deliverable:** Fully functional, SEO-optimized site

---

## DAY 6: CLIENT REVIEW & REVISIONS

### Morning (1 hour)
□ Do final quality check yourself
□ Fix any obvious issues
□ Take screenshots of all pages
□ Send preview link to client with instructions

### Email Template to Client:

> Subject: Your Website is Ready for Review!
> 
> Hi [Name],
> 
> Great news - your website is ready to review!
> 
> Preview Link: [URL]
> 
> Please review everything carefully:
> - Check all text for accuracy
> - Make sure contact info is correct
> - Test the contact form
> - Look at it on your phone
> - Let me know what you'd like changed
> 
> I need your feedback by end of day tomorrow so we can make any changes and launch on schedule.
> 
> If you love it as-is, we can launch right away!
> 
> Thanks,
> [Your Name]

### Afternoon (Variable)
□ Wait for client feedback
□ Make revision list
□ Prioritize changes (quick vs. time-consuming)

**End of Day 6 Goal:** Client has reviewed site and provided feedback

---

## DAY 7: FINAL REVISIONS & LAUNCH

### Morning (2-3 hours)
□ Implement all client-requested changes
□ Final round of testing
□ Verify all forms work
□ Check all links one more time
□ Test on mobile again

### Afternoon (2 hours)
□ Get final client approval
□ Collect final payment
□ Point domain to live site
□ Enable SSL certificate
□ Submit sitemap to Google Search Console
□ Set up Google Business Profile (Premium package)
□ Send launch email to client with instructions

>

>

>

> [Your Name]

**End of Day 7 Deliverable:** Live, fully-functional website!

---

## POST-LAUNCH (Days 8-14)

□ Monitor for any issues
□ Check that search engines are indexing site
□ Set up Google Business Profile (if Premium)
□ Follow up with client after 1 week
□ Ask for testimonial
□ Request referrals

## TIME BREAKDOWN

**Total Time per Project: 20-25 hours**

- Day 1: 4-6 hours (setup)
- Day 2: 5-6 hours (home + about)
- Day 3: 5-6 hours (services + gallery)
- Day 4: 4-6 hours (contact + functionality)
- Day 5: 5-6 hours (SEO + polish)
- Day 6: 1-2 hours (review prep)
- Day 7: 4-5 hours (revisions + launch)

**Effective hourly rate:**
- Essential ($497) / 20 hours = $24.85/hour
- Premium ($997) / 25 hours = $39.88/hour

**As you get faster, these numbers improve significantly.**

## COMMON ISSUES & SOLUTIONS

**Client is slow to provide materials:**
- Set a deadline: "I need photos by Day 3 to stay on schedule"
- Offer alternatives: "I can use stock photos temporarily"
- Build contract clause: "Delays in providing materials extend timeline"

**Client wants major scope changes mid-project:**
- "Happy to add that, but it will require a change order"
- Quote additional cost and time
- Don't do scope creep for free

**Client asks for unlimited revisions:**
- Contract specifies 2 rounds
- "I can do those changes for $50/hour or bundle them in a maintenance plan"

**You encounter technical issues:**
- Google it (seriously, 90% of issues are solved this way)
- Ask AI assistants (Claude, ChatGPT)
- Post in developer forums
- Don't spend more than 1 hour stuck - ask for help

---

## EFFICIENCY TIPS

1. **Use your existing demos as templates** - Don't start from scratch every time
2. **Create reusable components** - Copy/paste and customize
3. **Build a snippet library** - Save common code blocks
4. **Batch similar tasks** - Do all image optimization at once
5. **Use AI for copywriting** - Claude/ChatGPT can draft content fast
6. **Have a project checklist** - Don't rely on memory
7. **Set time blocks** - Don't let projects drag on
8. **Communicate proactively** - Update client every 2-3 days

---

## WHEN THINGS GO WRONG

**Missing Deadline:**
Email client immediately: "Hey [Name], we've hit a small delay because [reason]. New launch date is [date]. Sorry for the inconvenience!"

**Client Hates the Design:**
"No problem - that's why we have revisions! Can you send me examples of sites you like so I understand your vision better?"

**Technical Issues on Launch:**
"We're experiencing a technical issue - working on it now. I'll have it resolved within [timeframe]."

**Client Disappears:**
After 7 days: "Hey [Name], just checking in - do you need more time to review?"
After 14 days: "I'll keep your project files for 30 days. After that, I'll need to close out the project."

---

## SCALING UP

**Once you've done 5-10 sites and have the process down:**

- Hire a VA to handle client communication
- Outsource copywriting ($50-100 per project)
- Outsource image editing ($20-50 per project)
- Focus only on design and development
- Take on 2-3 projects simultaneously
- Increase prices (you're more experienced now)

**Example:**
- 3 sites per week = $1,500-$3,000/week
- 12 sites per month = $6,000-$12,000/month
- Outsource $150/site = $1,800/month in costs
- Net profit = $4,200-$10,200/month
