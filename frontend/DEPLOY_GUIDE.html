Step 6 — Update Price IDs in Edge Functions Action Required

Once you have the Price IDs from Step 5, update each edge function in supabase/functions/. Here's exactly what to find and replace in each file:

create-seo-package-checkout/index.ts — find unit_amount: 29900 and add the price ID, or use price: "price_YOUR_ID" in the session line items.

create-audit-checkout/index.ts — same pattern, unit_amount: 2900

create-gbp-subscription/index.ts — find the price_data block and replace with price: "price_YOUR_ID"

create-camp-listing-checkout/index.ts — same as GBP

The functions already work with hardcoded amounts (unit_amount). Price IDs are only needed if you want the product to appear in your Stripe dashboard reports by name. If you skip this, checkout still works — it just shows as a custom amount.

Step 7 — Schedule Cron Jobs in Supabase Action Required

These automation functions need to be scheduled. Go to Supabase → Edge Functions → Cron (or use pg_cron in SQL Editor) and add:

-- Run daily at 9am (review requests + drip emails) SELECT cron.schedule('send-review-request-daily', '0 9 * * *', $$SELECT net.http_post(url:='https://zmyczlfuufhngzovkjdh.supabase.co/functions/v1/send-review-request', headers:='{"Authorization":"Bearer YOUR_ANON_KEY"}'::jsonb)$$ ); -- Run weekly Monday 8am (GBP posts for clients) SELECT cron.schedule('auto-gbp-posts-weekly', '0 8 * * 1', $$SELECT net.http_post(url:='https://zmyczlfuufhngzovkjdh.supabase.co/functions/v1/auto-gbp-posts', headers:='{"Authorization":"Bearer YOUR_ANON_KEY"}'::jsonb)$$ );
Replace YOUR_ANON_KEY with your Supabase project's anon key (found in Project Settings → API).
