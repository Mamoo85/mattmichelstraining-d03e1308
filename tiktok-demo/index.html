Step 3 of 4 — video.upload
🎬 video.upload

AI-Generated Video
Uploaded via FILE_UPLOAD

Our system generates a lifestyle video (AI images → AVI/MJPEG, 8s), then uploads it to TikTok using the Content Posting API FILE_UPLOAD method. The upload initializes with /v2/post/publish/video/init/, then sends the byte stream in a single chunk PUT request.

POST open.tiktokapis.com/v2/post/publish/video/init/ 
{
  "post_info": {
    "title": "My AI posted 5 products… #sidehustle",
    "privacy_level": "PUBLIC_TO_EVERYONE"
  },
  "source_info": {
    "source": "FILE_UPLOAD",
    "video_size": 2097152,
    "chunk_size":  2097152,
    "total_chunk_count": 1
  }
}
PUT <upload_url> — byte stream, Content-Range: bytes 0-…

Step 4 of 4 — video.publish
📤 video.publish

Video Published
to TikTok Feed

After the chunk upload succeeds, TikTok processes the video asynchronously and publishes it. We poll /v2/post/publish/status/fetch/ using the publish_id and log the final status to our database with the video.publish scope confirming public posting.

POST open.tiktokapis.com/v2/post/publish/status/fetch/ 
{
  "publish_id": "v_sandbox_pub_88f2…"
}

// Response:
{
  "status": "PUBLISH_COMPLETE",
  "publicaly_available_post_id": ["7380123456789012"]
}
